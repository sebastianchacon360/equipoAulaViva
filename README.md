Equipo-AulaViva-

Plataforma SaaS multi-tenant con tutor IA para instituciones educativas. 

 
Descripción:

AulaViva es una plataforma educativa orientada a colegios que permite 
gestionar estudiantes, docentes, cursos y evaluaciones, incorporando 
un tutor IA basado en RAG. 

 
 Objetivo 

Crear un MVP seguro, escalable y multi-tenant que mejore la experiencia 
educativa y entregue apoyo personalizado a los estudiantes.
